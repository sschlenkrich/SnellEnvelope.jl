SnellEnvelope.bachelier_price — Method
bachelier_price(strike, forward, nu, call_put)

Calculate Vanilla option price $V$ in Bachelier model.

Argument strike ($K$) represents the option strike, forward ($F$) is the forward price of the underlying $S$, i.e. $F = E[S(T)]$ in the respective pricing measure.

Argument nu represents the standard deviation of the forward price. For annualised normal volatility σ, we have ν = σ √T. Finally, call_put is the call (+1) or put (-1) option flag.

Note that we do not test for vanishing volatility. Zero volatility may cause floating point errors.

Calcuate the Snell envelope using backward induction.

Arguments

  • payoffs: A vector of payoff functions, one for each exercise date.
  • std_devs: A vector of standard deviations, one for each exercise date.
  • model_type: The model type, either ModelType.normal or ModelType.lognormal.
  • lambda: The number of standard deviations to use for the integration range.
  • n_points: The number of points to use for the integration.

SnellEnvelope.black_price — Method
black_price(strike, forward, nu, call_put)

Calculate Vanilla option price V in Black model.

Argument strike ($K$) represents the option strike, forward ($F$) is the forward price of the underlying $S$, i.e. $F = E[S(T)]$ in the respective pricing measure.

Argument nu represents the standard deviation of the forward price. For annualised lognormal volatility σ, we have $ν = σ √T$. Finally, call_put is the call (+1) or put (-1) option flag.

Note that we allow negative standard deviation ν. This allows modelling negative skew for shifted-lognormal models.

Note that we do not test for vanishing volatility. Zero volatility may cause floating point errors.

We allow broadcasting for arguments.

SnellEnvelope.swaption_snell_envelope — Method
swaption_snell_envelope(
    swap_rates::Vector{Float64},
    strike_rates::Vector{Float64},
    annuities::Vector{Float64},
    prices::Vector{Float64},
    call_put::Float64,
    model_type::ModelType,
    lambda::Float64,
    n_points::Int64,
    )

Calculate the Snell envelope for a sequence of European swaptions with given swap rates, strike rates, annuities, and prices.

The call_put parameter indicates whether the options are calls (+1) or puts (-1).

The model_type specifies whether to use the normal (Bachelier) or lognormal (Black) model.

The lambda parameter specifies the number of standard deviations for integration, and n_points specifies the number of points for interpolation.

SnellEnvelope.swaption_switch_value — Method
swaption_switch_value(
    swap_rates::Vector{Float64},
    strike_rates::Vector{Float64},
    annuities::Vector{Float64},
    prices::Vector{Float64},
    call_put::Float64,
    model_type::ModelType,
    lambda::Float64,
    n_points::Int64,
    )

Calculate the switch value for a sequence of European swaptions.

For details on the inputs, see swaption_snell_envelope.

The switch value is defined as the difference between the Snell envelope and the maximum of the prices of the European swaptions.

Switch value is floored at zero to capture small deviations due to numerical errors for out-of-the-money swaptions.
